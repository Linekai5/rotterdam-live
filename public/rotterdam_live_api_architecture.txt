# Rotterdam Live API — Architectural Specification & System Documentation

> [!NOTE]
> **Platform Version:** 1.6.0 (Sprint: Live Weather, Buienradar Rain Nowcast, KNMI Station Telemetry & RainViewer Radar Tiles)  
> **Environment:** Hetzner Cloud Linux VPS (Rotterdam Dockerized Stack)  
> **Contract:** Sub-30ms response times, zero synchronous external API calls on client requests, automated PostGIS district assignment, strict RFC 7946 GeoJSON.

## 1. Executive Summary & Core Architecture

The **Rotterdam Live API** (`rotterdam-live-api`) is an asynchronous, high-throughput spatial data platform designed to power the real-time interactive map of Rotterdam (`rott-live`). It aggregates:
1. **High-Frequency Situational Feeds:** P2000 112 emergency dispatches, movable bridge openings, and parking garage live occupancy.
2. **Municipal Infrastructure & Environment:** Roadworks, Rijkswaterstaat waterways/NAP water levels, DCMR air quality, and Stedin electrical grid power outages.
3. **Hyper-Accurate Live Weather & Radar Subsystem:**
   - **Minute-by-minute 2-hour precipitation nowcast** from Buienradar radar reflectivity.
   - **Real-time KNMI telemetry** from official observation stations (Rotterdam The Hague Airport `6344`, Hoek van Holland `6330`, Geulhaven `6343`).
   - **MapLibre-ready Animated Weather Radar Tile Stream** from RainViewer with timeline timestamps and Slippy tile templates.
4. **Semi-Static Civic Amenities:** Public toilets, drinking water taps, EV chargers, AEDs, and **8,803 verified outdoor cameras**.
5. **Official Kadaster BAG Addresses:** **382,814 official doorway points** covering every registered Dutch building in Gemeentecode `0599` (Rotterdam) with building purpose (`gebruiksdoel`), postal codes, surface areas, and construction years.
6. **Verified Commercial Retail Infrastructure:** **2,950 retail venues, supermarkets, and shops**, spatially linked (97.3% linkage) to official Kadaster BAG buildings and doorway addresses.
7. **Unified Global Spatial Search Engine:** Sub-10ms multi-domain search across addresses, retail facilities, and civic amenities powered by PostgreSQL `pg_trgm` similarity ranking.

## 2. Infrastructure & Container Topology

The application runs via Docker Compose on an internal bridged network (`rotterdam_net`):

| Container Name | Service | Internal Port | Host Port | Role |
| :--- | :--- | :--- | :--- | :--- |
| `rotterdam_live_api` | FastAPI / Uvicorn | 8000 | `${BIND_ADDRESS}:8000` | Asynchronous REST API serving cached GeoJSON and live weather. |
| `rotterdam_live_worker` | Python Ingestion Worker | — | — | APScheduler background daemon running all ingestion loops. |
| `rotterdam_live_db` | PostgreSQL 16 + PostGIS | 5432 | `localhost:5432` | PostGIS spatial database with GiST and pg_trgm GIN indexes. |
| `rotterdam_live_redis` | Redis 7 Alpine | 6379 | `localhost:6379` | In-memory cache delivering sub-5ms responses. |

## 3. The Weather & Map Radar Subsystem

Implemented in [`app/ingestion/weather_harvester.py`](file:///home/homeaccount/rotterdam-live-api/app/ingestion/weather_harvester.py) and [`app/api/v1/weather.py`](file:///home/homeaccount/rotterdam-live-api/app/api/v1/weather.py).

### A. Buienradar 2-Hour Rain Nowcast
* **Source:** `https://gpsgadget.buienradar.nl/data/raintext/?lat={lat}&lon={lon}`
* **Format:** Text lines of `RRR|HH:MM` in 5-minute increments for 2 hours (24 items).
* **Meteorological Conversion:**
  $$\text{intensity (mm/h)} = 10^{\frac{\text{value} - 109}{32}}$$
  *(value `000` = `0.0 mm/h`, values $< 077$ = drizzle, $> 200$ = heavy downpours).*
* **Telemetry Derived:**
  * `will_rain_in_2h` (bool)
  * `max_intensity_mm_h` (float)
  * `first_rain_in_minutes` (int, or null if dry)
  * `summary` (Dutch sentence: e.g. *"Droog momenteel, regen verwacht over circa 25 minuten"*).

### B. KNMI Regional Weather Stations
* **Source:** `https://data.buienradar.nl/2.0/feed/json`
* **Target Stations:**
  1. `6344`: **Rotterdam The Hague Airport (Zestienhoven)** (Primary, District: Overschie)
  2. `6330`: **Hoek van Holland** (Coastal / Port winds, District: Botlek-Europoort-Maasvlakte)
  3. `6343`: **Rotterdam Geulhaven** (Port / Industrial, District: Botlek-Europoort-Maasvlakte)
* **Measurements Stored:**
  * Air & feels-like temperature (°C), ground temperature (°C), relative humidity (%)
  * Barometric air pressure (hPa)
  * Wind speed (m/s, km/h, and Beaufort), wind gusts (m/s, km/h), wind direction (degrees and compass string)
  * Precipitation intensity (mm/h), rainfall last hour & 24 hours (mm)
  * Visibility (meters), solar irradiance (W/m²), Dutch condition description, and icon URLs.

### C. RainViewer Animated Radar Tile Stream for MapLibre
* **Source:** `https://api.rainviewer.com/public/weather-maps.json`
* **Tile URL Pattern:** `https://tilecache.rainviewer.com/v2/radar/{path}/512/{z}/{x}/{y}/2/1_1.png`
* **Capabilities:** Supplies an ordered timeline of past frames (and future nowcast frames) with Unix timestamps and formatted UTC timestamps, allowing the frontend to smoothly animate rain cloud movements.

## 4. REST API Specification (`/api/v1/`)

All endpoints return RFC 7946 GeoJSON or structured JSON with sub-30ms latency (sub-5ms from Redis).

### A. Live Weather Endpoints (`/api/v1/weather`)

| Endpoint | Method | Description | Cache TTL |
| :--- | :--- | :--- | :--- |
| `/api/v1/weather/live` | `GET` | Unified instant overview of current Rotterdam weather, wind, rain status, and natural language summary. | 300s (5m) |
| `/api/v1/weather/rain-forecast` | `GET` | 2-hour minute-by-minute rain nowcast (`lat`, `lon` query params). | 300s (5m) |
| `/api/v1/weather/radar` | `GET` | Animated radar tile timeline and MapLibre tile URL templates. | 300s (5m) |
| `/api/v1/weather/stations` | `GET` | GeoJSON FeatureCollection of official KNMI stations in Greater Rotterdam. | 600s (10m) |
| `/api/v1/weather/stations/{station_id}` | `GET` | Single KNMI station by ID (`6344`, `6330`, `6343`). | 600s (10m) |

### B. Kadaster BAG Addresses Endpoints (`/api/v1/addresses`)
* `GET /api/v1/addresses`: Filter 382,814 official BAG verblijfsobjecten by district, purpose, postal code, bbox.
* `GET /api/v1/addresses/search`: Autocomplete / pg_trgm fuzzy search.
* `GET /api/v1/addresses/stats`: Breakdown by purpose and district.
* `GET /api/v1/addresses/{address_id}`: Single address lookup.

### C. Retail Infrastructure Endpoints (`/api/v1/retail`)
* `GET /api/v1/retail`: Filter 2,950 verified retail venues by category, brand, district, bbox.
* `GET /api/v1/retail/supermarkets`: Supermarkets query (Albert Heijn, Jumbo, Dirk, PLUS, Aldi, Lidl).
* `GET /api/v1/retail/stats`: Statistics on retail categories, brands, and BAG linkage.
* `GET /api/v1/retail/{venue_id}`: Single venue lookup.

### D. Unified Global Spatial Search (`/api/v1/search`)
* `GET /api/v1/search?q={query}`: Multi-domain spatial search across addresses, retail facilities, and civic amenities ranked by trigram similarity.

## 6. Frontend Integration Guide (MapLibre GL & Svelte)

### A. Rendering Animated Weather Radar in MapLibre GL
Add RainViewer radar tile raster source and layer:

```javascript
// Fetch radar metadata
const res = await fetch('http://<API_HOST>:8000/api/v1/weather/radar');
const radar = await res.json();
const latestFrame = radar.latest_frame;

// Add raster source with latest radar frame
map.addSource('rain-radar', {
  type: 'raster',
  tiles: [latestFrame.tile_url],
  tileSize: 512,
  attribution: 'RainViewer / KNMI'
});

map.addLayer({
  id: 'rain-radar-layer',
  type: 'raster',
  source: 'rain-radar',
  paint: {
    'raster-opacity': 0.75,
    'raster-fade-duration': 200
  }
});

// To animate through timeline:
let frameIndex = 0;
function animateRadar() {
  const frame = radar.past_frames[frameIndex];
  const source = map.getSource('rain-radar');
  if (source) {
    source.setTiles([frame.tile_url]);
  }
  frameIndex = (frameIndex + 1) % radar.past_frames.length;
}
setInterval(animateRadar, 1500);
```

### B. Consuming Live Weather Overview
```javascript
const liveRes = await fetch('http://<API_HOST>:8000/api/v1/weather/live');
const weather = await liveRes.json();

console.log(`${weather.summary}`);
// "Zwaar bewolkt in Rotterdam (14.2°C), droog komende 2 uur met matige wind (3 Bft ZZO)"
```
