## 1. Executive Summary & Core Architecture

The **Rotterdam Live API** (`rotterdam-live-api`) is an asynchronous, high-throughput geospatial platform engineered to power the real-time situational map of Rotterdam (`rott-live`). It serves as the single source of truth for all situational, municipal, commercial, environmental, and meteorological data across the municipality of Rotterdam (Gemeentecode `0599`).

The database currently holds **over 396,000 spatial records** indexed with PostGIS GiST and PostgreSQL `pg_trgm` GIN indexes.

## 5. The Live Weather & Precipitation Radar Subsystem

Implemented in [`weather_harvester.py`](file:///home/homeaccount/rotterdam-live-api/app/ingestion/weather_harvester.py) and [`weather.py`](file:///home/homeaccount/rotterdam-live-api/app/api/v1/weather.py).

### A. Buienradar 2-Hour Rain Nowcast
* **Source:** `https://gpsgadget.buienradar.nl/data/raintext/?lat={lat}&lon={lon}`
* **Format:** Text lines of `RRR|HH:MM` in 5-minute increments for 2 hours (24 items).
* **Mathematical Conversion Formula:**
  $$\text{intensity (mm/h)} = 10^{\frac{\text{value} - 109}{32}}$$
  *(value `000` = `0.0 mm/h`, values $< 077$ = drizzle, $> 200$ = heavy downpours).*
* **Derived Telemetry:** `will_rain_in_2h` (bool), `max_intensity_mm_h`, `first_rain_in_minutes`, `currently_raining`, and Dutch natural language summary.

### B. KNMI Regional Weather Stations
* **Source:** `https://data.buienradar.nl/2.0/feed/json`
* **Target Stations:**
  1. `6344`: **Rotterdam The Hague Airport (Zestienhoven)** (Primary, District: Overschie)
  2. `6330`: **Hoek van Holland** (Coastal / Port winds, District: Botlek-Europoort-Maasvlakte)
  3. `6343`: **Rotterdam Geulhaven** (Port / Industrial, District: Botlek-Europoort-Maasvlakte)
* **Measurements:** Air & feels-like temperature (°C), ground temperature (°C), humidity (%), air pressure (hPa), wind speed (m/s, km/h, Bft), wind gusts (m/s, km/h), wind direction (degrees & compass), precipitation (mm/h), rainfall last 1h/24h (mm), visibility (m), sun power (W/m²), Dutch condition description, icon URLs.

### C. RainViewer Animated Radar Tile Stream for MapLibre
* **Source:** `https://api.rainviewer.com/public/weather-maps.json`
* **Tile URL Pattern:** `https://tilecache.rainviewer.com/v2/radar/{path}/512/{z}/{x}/{y}/2/1_1.png`
* **Output:** Ordered timeline of past frames (and future nowcast frames) with Unix timestamps and formatted UTC strings for MapLibre GL raster layer animations.

## 8. Frontend Integration Guide (Svelte & MapLibre GL)

### A. Consuming Animated Weather Radar Layer in MapLibre GL
```javascript
// 1. Fetch radar timeline metadata
const res = await fetch('http://<API_HOST>:8000/api/v1/weather/radar');
const radar = await res.json();

// 2. Add raster source using latest frame
map.addSource('rain-radar', {
  type: 'raster',
  tiles: [radar.latest_frame.tile_url],
  tileSize: 512,
  attribution: 'RainViewer / KNMI'
});

map.addLayer({
  id: 'rain-radar-layer',
  type: 'raster',
  source: 'rain-radar',
  paint: {
    'raster-opacity': 0.75,
    'raster-fade-duration': 200
  }
});

// 3. Play animation through historical frames
let frameIndex = 0;
setInterval(() => {
  if (!radar.past_frames.length) return;
  const frame = radar.past_frames[frameIndex];
  const source = map.getSource('rain-radar');
  if (source) source.setTiles([frame.tile_url]);
  frameIndex = (frameIndex + 1) % radar.past_frames.length;
}, 1500);
```

### B. Consuming Live Weather Overview
```javascript
const res = await fetch('http://<API_HOST>:8000/api/v1/weather/live');
const weather = await res.json();

console.log(weather.summary);
```

### C. Consuming Kadaster BAG Addresses in Search & Autocomplete
```javascript
async function searchAddresses(query) {
  const res = await fetch(`http://<API_HOST>:8000/api/v1/addresses/search?q=${encodeURIComponent(query)}&limit=5`);
  const data = await res.json();
  return data.features.map(f => ({
    addressId: f.properties.address_id,
    display: f.properties.display_name,
    purpose: f.properties.purpose,
    coordinates: f.geometry.coordinates
  }));
}
```
