> [!NOTE]
> **Platform Version:** 1.8.0 (The /events Domain: Ticketmaster, Stadium Fixtures, Municipal Festivals & Open Cultural Agendas)  
> **Environment:** Hetzner Cloud Linux VPS (Rotterdam Dockerized Stack)

> **Frontend Repository:** [`github.com/Linekai5/Rott-live`](https://github.com/Linekai5/Rott-live) (Private, main branch synced)  
> **Contract:** Sub-30ms GeoJSON API response times (sub-5ms cached in Redis), zero synchronous external API queries during client HTTP requests, automated PostGIS municipal district validation, strict RFC 7946 GeoJSON compliance.

## 1. Executive Summary & Core Architecture

The **Rotterdam Live API** (`rotterdam-live-api`) is an asynchronous, high-throughput geospatial platform engineered to power the real-time situational map of Rotterdam (`rott-live`). It serves as the single source of truth for all situational, municipal, commercial, environmental, meteorological, and cultural event data across the municipality of Rotterdam (Gemeentecode `0599`).

The database currently holds **over 396,400 spatial records** indexed with PostGIS GiST and PostgreSQL `pg_trgm` GIN indexes.

## 2. Infrastructure & Container Topology

The production platform runs on an internal Docker bridge network (`rotterdam_net`):

| Container Name | Service | Internal Port | Host Port | Role & Resource Allocation |
| :--- | :--- | :--- | :--- | :--- |
| `rotterdam_live_api` | FastAPI / Uvicorn | `8000` | `0.0.0.0:8000` | Asynchronous REST API serving cached GeoJSON, live telemetry, events, and unified spatial search. |
| `rotterdam_live_worker` | Python Ingestion Worker | — | — | APScheduler background daemon running all 14 ingestion pipelines. |
| `rotterdam_live_db` | PostgreSQL 16 + PostGIS 3.4 | `5432` | `127.0.0.1:5432` | PostGIS spatial database on persistent volume `pgdata`. |
| `rotterdam_live_redis` | Redis 7 Alpine | `6379` | `127.0.0.1:6379` | In-memory key-value cache and spatial bbox quantizer on volume `redisdata`. |

## 5. The Live Weather & Precipitation Radar Subsystem

Implemented in [`weather_harvester.py`](file:///home/homeaccount/rotterdam-live-api/app/ingestion/weather_harvester.py) and [`weather.py`](file:///home/homeaccount/rotterdam-live-api/app/api/v1/weather.py).

### A. Buienradar 2-Hour Rain Nowcast
* **Source:** `https://gpsgadget.buienradar.nl/data/raintext/?lat={lat}&lon={lon}`
* **Format:** Text lines of `RRR|HH:MM` in 5-minute increments for 2 hours (24 items).
* **Mathematical Conversion Formula:**
  $$\text{intensity (mm/h)} = 10^{\frac{\text{value} - 109}{32}}$$
* **Derived Telemetry:** `will_rain_in_2h` (bool), `max_intensity_mm_h`, `first_rain_in_minutes`, `currently_raining`, and Dutch natural language summary.

### B. KNMI Regional Weather Stations
* **Source:** `https://data.buienradar.nl/2.0/feed/json`
* **Target Stations:** `6344` (Airport / Overschie), `6330` (Hoek van Holland), `6343` (Geulhaven).

### C. RainViewer Animated Radar Tile Stream for MapLibre
* **Source:** `https://api.rainviewer.com/public/weather-maps.json`
* **Tile URL Pattern:** `https://tilecache.rainviewer.com/v2/radar/{path}/512/{z}/{x}/{y}/2/1_1.png`
